# VK-бот PromptMaster

Бот для сообщества VK на **vkbottle** (Long Poll). Логика совпадает с консольным прототипом в `vk_console_bot/`: классификатор → разбор текста → улучшение промпта, уточнения по кнопке «Готово».

Сейчас рабочие зелёные кнопки:
- **`написать текст`** (принудительно ведёт в ветку 1)
- **`объяснить`** (принудительно ведёт в ветку 6)

Серые кнопки — сценарии в разработке.

Инструкции для моделей лежат в **`vk_console_bot/instructions.txt`** — меняйте их там для всех клиентов (консоль и VK).

## Зависимости

```powershell
cd путь\к\PromptMaster\vk_prompt_bot
pip install -r requirements.txt
```

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните:

| Переменная | Описание |
|------------|----------|
| `VK_GROUP_TOKEN` или `vk_group_token` | Токен сообщества с правами на сообщения |
| `OPENAI_API_KEY` | Обязательно для пайплайна |
| `OPENAI_BASE_URL` | По умолчанию proxy API из кода движка |
| `OPENAI_MODEL` | По умолчанию `gpt-4o-mini` |

Дополнительно можно положить `.env` в корень репозитория или в `vk_console_bot/` — они подгружаются при старте.

## Запуск

```powershell
cd путь\к\PromptMaster\vk_prompt_bot
python vk_bot.py
```

В настройках сообщества: включить **Сообщения сообщества**, в API — **Long Poll** для типа событий, который использует бот.

## Связанные каталоги

| Каталог | Назначение |
|---------|------------|
| `vk_console_bot/` | Активный движок: `main.py`, `instruction_loader.py`, `instructions.txt` |
| `vk_console_bot_original/` | Независимая копия консольной версии «на сохранение» |

Старый путь запуска `vk_echo_bot/vk_prompt_bot.py` перенаправляет сюда для совместимости.
